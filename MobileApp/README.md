# Cafevania Gourmet - Waiter Mobile App

Müasir Restoran İdarəetmə Sistemi — Ofisiant Terminalı.

> [!IMPORTANT]
> **DİQQƏT:** Bu proyekt yalnız təhsil məqsədi daşıyır. "Cafevania Gourmet" hər hansı real bir restorana aid deyil.

## 📱 Xüsusiyyətlər
- **Sürətli Sifariş:** Masa üzərindən məhsulların sürətli seçimi və kassaya göndərilməsi.
- **Real-vaxt Sinxronizasiya:** Kassa ilə anlıq məlumat mübadiləsi.
- **Masa Statusu:** Hansı masaların dolu və ya hazırlıq mərhələsində olduğunu izləmə.
- **Premium Mobil Dizayn:** Rahat və sürətli naviqasiya, tünd rejim dəstəyi.
- **Kateqoriya Filtrləri:** Menyu daxilində sürətli filtrasiya və axtarış.

## 🛠 Texnologiya Stokumuz
- **Frontend:** Vue 3
- **Platform:** Capacitor (iOS/Android üçün)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS 4
- **Database:** Firebase Firestore

## 📦 Quraşdırma və İstifadə

### Addımlar
1. Repo-nu klonlayın.
2. Dependency-ləri yükləyin:
   ```bash
   npm install
   ```
3. Development rejimində işə salın:
   ```bash
   npm run dev
   ```
4. Android proyektini yeniləyin:
   ```bash
   npm run build
   npx cap sync android
   ```
5. Android Studio-da açın:
   ```bash
   npx cap open android
   ```
