# Cafevania Gourmet - Desktop Kassa App

Müasir Restoran İdarəetmə Sistemi — Kassa Terminalı.

> [!IMPORTANT]
> **DİQQƏT:** Bu proyekt yalnız təhsil məqsədi daşıyır. "Cafevania Gourmet" hər hansı real bir restorana aid deyil.

## 🚀 Xüsusiyyətlər
- **Real-vaxt Sifariş İdarəetməsi:** Firebase vasitəsilə ofisiantlarla anlıq sinxronizasiya.
- **Masa İdarəetməsi:** Masaların doluluq və rezervasiya statusunun vizual təqdimatı.
- **Premium Dizayn:** Midnight Navy qaranlıq rejimi və qızılı rəng tonları ilə professional interfeys.
- **Hesabatlar:** Günlük satışların və fəaliyyətin analizi.
- **Klaviatura Qısayolları:** Sürətli əməliyyatlar üçün (F2 - Yeni sifariş, F11 - Tam ekran və s.).
- **Çek Çapı:** Müştərilər üçün professional çeklərin hazırlanması.

## 🛠 Texnologiya Stokumuz
- **Frontend:** Vue 3 (Composition API)
- **Framework:** Electron (Desktop tətbiqi üçün)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS 4
- **Database:** Firebase Firestore (Real-time updates)

## 📦 Quraşdırma və İstifadə

### Tələblər
- Node.js (Latest LTS)
- NPM və ya Yarn

### Addımlar
1. Repo-nu klonlayın:
   ```bash
   git clone [repo-url]
   ```
2. Dependency-ləri yükləyin:
   ```bash
   npm install
   ```
3. Development rejimində işə salın:
   ```bash
   npm run dev
   ```
4. Production build (EXE) yaradın:
   ```bash
   npm run build
   ```
